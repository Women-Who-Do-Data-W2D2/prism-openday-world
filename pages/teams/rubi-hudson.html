Preference Drift in Language Models

Mentor: Rubi Hudson

Research Lead, Principled Agents

About this project

As a model is trained on certain capabilities, do its preferences over which tasks it wants to do shift in ways it cannot anticipate? If a model trained heavily on coding begins to "want" coding tasks more than before, that has direct implications for how cohesive an agent the model is becoming, which is itself a safety-relevant signal.
